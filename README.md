# persister-selection-bound

Analysis code and results for

> Alvarez I. **Response-adjusted selection bounds distinguish pre-treatment selection from induced
> state change in single-cell perturbation data.** (2026, submitted).

The method itself is released as the Python package
[`selbound`](https://github.com/illychd7/selbound)
([doi:10.5281/zenodo.23934920](https://doi.org/10.5281/zenodo.23934920)).
This repository holds the scripts that produce every number, table and figure of the paper from
the public GEO files, with fixed seeds, and the results they produced.

Version 1.0.0 of this repository accompanied an earlier version of the manuscript ("Fate is
selected, state is induced: response-adjusted inference in single-cell drug tolerance").

## Layout

```
scripts/    analysis, preprocessing and figure scripts (all paths in scripts/config.py)
results/    JSON/CSV/NPZ outputs used in the paper (regenerated by the scripts)
inputs/     tnbc_authors_obs.csv.gz: cell metadata exported from the authors' GSE291678 h5ad
data/       created by scripts/fetch_data.sh (not tracked)
figures/    created by the figure scripts (not tracked)
```

Folders can be moved with the environment variables `PSB_DATA`, `PSB_RESULTS` and `PSB_FIGS`.

## Installation

Python 3.13 and, for the melanoma data only, R >= 4.3 with SeuratObject.

```bash
pip install -r requirements.txt
```

## Data

| dataset | GEO | used for |
|---|---|---|
| PC9 Watermelon time course and pooled A375/HT29/PC9 (Oren et al., Nature 2021) | GSE150949 | Figs. 2–6, 7A; Tables S1, S3, S4 |
| MDA-MB-231 ClonMapper scRNA-seq under doxorubicin (Morgan et al., 2025) | GSE291678 | Fig. 7B |
| MDA-MB-231 ClonMapper barcode sequencing | GSE291679 | Fig. 7B |
| WM4237-1 MeRLin in vitro, dabrafenib + trametinib (Li et al., 2025) | GSE299711 | Fig. 7C |

```bash
bash scripts/fetch_data.sh      # about 3.5 GB; also exports the MeRLin Seurat objects with R
```

The PC9 survival budgets use lineage survival and divisions digitised from Fig. 1b of the
Oren et al. preprint (bioRxiv 2020.06.05.136358); the digitised table is shipped as
`results/fig1b_digitized.npz` (`scripts/digitize_fig1b.py` documents how it was read).

## Reproducing the paper

Run from the repository root. Times are for two CPU cores.

```bash
# PC9 preprocessing (about 1 min) -> data/pc9/pc9_pp.npz
python scripts/pc9_preprocess_keep.py

# PC9 results
python scripts/main_table.py              # Table S1, Fig. 5            -> main_table.json
python scripts/run_real.py                # clone decomposition, Fig. 6, Table S4 -> real_results.json
python scripts/within_vs_between.py       # Fig. 6                      -> within_vs_between.json
python scripts/dispersion_check.py        # Fig. 6, variance controls   -> dispersion_check.json
python scripts/fate_predictability.py     # Fig. 6                      -> fate_predictability.json
python scripts/gene_panel_control.py      # Fig. S1                     -> gene_panel_control.json
python scripts/panel_direction_check.py   # Fig. S2                     -> panel_direction_check.json
python scripts/crossfit_appendixA.py      # Table S3                    -> crossfit_appendixA.csv
python scripts/pooled_decomp.py           # Fig. 7A, pooled lines       -> pooled_decomp.json

# Simulation, semi-synthetic validation, benchmark, power
python scripts/sim_fig1.py                # Fig. 1B                     -> sim_fig1.csv/.json
python scripts/semisynthetic.py           # Fig. 2                      -> semisynthetic.json
python scripts/benchmark.py               # Fig. 3, S3                  -> benchmark_results.json
python scripts/summarize_benchmark.py     #                             -> rejection_rates.csv
python scripts/bench_milo.py main 20      # Fig. 3A, Milo (pertpy)      -> milo_official_results.json
python scripts/bench_milo.py sens 20      # Fig. 3B, Milo k sensitivity -> milo_official_sensitivity.json
python scripts/sensitivity.py             # comparator hyperparameters  -> sensitivity.json
python scripts/power_runtime.py           # Fig. 4                      -> power.csv, runtime.csv

# Breast cancer and melanoma (Fig. 7B, C)
python scripts/preprocess_newdata.py      # -> data/newdata/{tnbc,merlin}_pp.npz
python scripts/run_newdata.py             # -> newdata_results.json
python scripts/selection_budget.py        # barcode-seq enrichment -> selection_budget_barcodeseq.csv

# Figures (read results/, write figures/)
python scripts/make_figs_v60.py           # Figs. 1, 4, 7  (fig_overview, fig_power, fig_generalization)
python scripts/make_figs_core.py          # Figs. 2, 5, 6  (fig_semisynthetic, fig_budget_adjusted, fig_clone_decomposition)
python scripts/make_figs_v55.py           # Figs. 3, S1, S2 (fig_benchmark, fig_gene_panels, fig_direction)
python scripts/fig_s3_comparators.py      # Fig. S3
```

`seltest.py` (bound and design ceiling), `preprocess.py` (count thinning), `decomposition.py`
(clone-level decomposition) and `benchmark.py` (semi-synthetic scenarios) are also imported as
modules. The same estimators are packaged, with tests, in `selbound`.

### Verification

Checked on 2026-11-03 in a clean folder starting from the GEO files:

- `main_table.json`, `pooled_decomp.json`, `newdata_results.json`,
  `selection_budget_barcodeseq.csv` and `rejection_rates.csv` are reproduced exactly;
- all ten figures of the paper (Figs. 1–7, S1–S3) are regenerated from `results/` with
  identical content;
- the MeRLin export (`export_merlin.R`) is byte-identical to the files used for the paper.

Two analyses were rebuilt after the original scripts were lost and are documented in their
headers: the known-response simulation (`sim_fig1.py`, Fig. 1B) and the clone-cross-fitted
response models (`crossfit_appendixA.py`, Table S3). The paper reports the values these scripts
produce.
